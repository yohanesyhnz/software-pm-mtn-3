# Migration Guide v2.0.0

## Perubahan Utama

- Frontend dipindahkan ke Next.js App Router.
- Backend utama menggunakan ASP.NET Core Web API pada .NET 10 LTS.
- Metadata versi dan audit trail disimpan pada direktori runtime `data/`.

## Sebelum Migrasi

1. Backup database, konfigurasi, master data, dan setting user.
2. Pastikan Node.js, pnpm, dan .NET 10 SDK tersedia.
3. Pastikan port frontend `3000` dan backend `5080` tersedia.

## Verifikasi

1. Jalankan build frontend dan backend.
2. Periksa `/api/health` dan `/api/software-versions/current`.
3. Periksa halaman `/software-versions` dan `/about`.

## Rollback

1. Hentikan aplikasi.
2. Pulihkan ZIP backup versi sebelumnya.
3. Deploy kembali tag `v1.8.5`.
4. Verifikasi health check, master data, dan audit trail.
