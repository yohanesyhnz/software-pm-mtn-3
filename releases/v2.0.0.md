# Release v2.0.0

**Tanggal:** 2026-08-04  
**Versi sebelumnya:** v1.8.5  
**Jenis perubahan:** Major

## Ringkasan

Modernisasi CMMS ke Next.js dan .NET 10 dengan Software Version Management, backup, rollback otomatis, audit trail, dan antarmuka SCADA industrial.

## New Features

- Software Version History dan Release Notes per versi.
- About Software dan Update Checker.
- Backup sebelum update dan audit trail administrator.

## Improvements

- Frontend Next.js App Router dan backend ASP.NET Core Web API.

## Fixed

- Isolasi compatibility script dashboard lama.

## Optimizations

- Build produksi Next.js dan persistence metadata atomik.

## Breaking Changes

- Migrasi arsitektur dan struktur project.
- Penambahan model data Software Version Management.

## Known Issues

- PostgreSQL dan PLC produksi memerlukan koneksi jaringan NAS/pabrik.

## Documentation

- README, CHANGELOG, VERSION, Release Notes, dan Migration Guide tersedia di repository.
