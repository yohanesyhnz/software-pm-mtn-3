⚙️ Konfigurasi IP & Address PLC Mesin

Opsional. Digunakan untuk membaca pencapaian hitungan produk secara otomatis.
Jika diaktifkan, sistem CMMS secara real-time menambah jam jalan (running hours) mesin & mengurai sisa usia spare part ketika PLC mengirim sinyal RUNNING.
Aktifkan jika status mesin aktual berlawanan dengan sinyal PLC (misal: mesin jalan terbaca STOP=1, atau mesin mati terbaca RUN=1). Jika aktif, nilai bit 1 diterjemahkan sebagai STOP (0), dan bit 0 sebagai RUNNING (1).
